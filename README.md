# КИНЕМА

Каталог фильмов и сериалов с плеером, выбором озвучки, субтитрами, пропуском заставок
и продолжением просмотра. Источником воспроизведения выступает **ваша собственная
медиатека через Jellyfin**, а каталог и метаданные приходят из TMDB.

## Что есть кроме каталога

- **Подбор по настроению** (`/picker`) — мастер из пяти шагов. Настроения собраны на
  ключевых словах TMDB, а не на жанрах: «временная петля» отбирает точнее, чем
  «фантастика». Состояние мастера целиком в URL, поэтому результат можно переслать.
- **Расширенные фильтры каталога** — жанры с исключением, длительность, планка
  рейтинга с порогом голосов, страна, язык оригинала, стриминги, статус сериала.
- **Карточка тайтла** — где смотреть легально, возрастной рейтинг региона, раздельные
  даты кино и цифры, бюджет и сборы, съёмочная группа по департаментам, галерея,
  ключевые слова как навигация, франшиза, отзывы.
- **Страницы персоны, франшизы и ключевого слова** — навигация не заканчивается
  тупиком на имени актёра.
- **Личные списки** — «смотреть позже» и «избранное» в localStorage, без аккаунта.

## Оформление

Тёмный монохром: почти чёрный холст, платиновый акцент, свечение вместо цвета.
Единственное цветное пятно на экране должен давать постер.

Слой токенов — `src/app.css`. Компоненты не знают цветов, они ходят через `var(--c-*)`,
поэтому добавить седьмую тему = дописать один блок. Ключи тем (`default`, `frost`,
`blue`, `teal`, `red`, `gray`) не менялись между версиями намеренно: они прибиты в
bootstrap-скрипте `src/app.html` и лежат в cookie у существующих пользователей.

## Как это устроено

Два слоя, которые встречаются только в одном месте — `src/lib/server/catalog.ts`:

| Слой | Отвечает за | Источник |
| --- | --- | --- |
| Каталог | Обложки, описания, жанры, актёры, сезоны | TMDB |
| Воспроизведение | Потоки, озвучки, субтитры, прогресс | Jellyfin |

Каталог показывает **всё**, что есть в TMDB, поэтому главная и подборки выглядят
полноценно. Кнопка «Смотреть» появляется только у того, что реально лежит в медиатеке —
остальное помечено как «нет в медиатеке».

### Ключевая деталь: как работает смена озвучки

Jellyfin отдаёт HLS-манифест **ровно с одной аудиодорожкой**. Переключить озвучку
внутри плеера нельзя — это ограничение сервера, а не недоработка клиента
(см. jellyfin/jellyfin#12516).

Поэтому смена озвучки реализована так:

```
запомнить позицию
  -> POST /api/playback/resolve с другим audioStreamIndex
  -> получить новый манифест
  -> переподключить hls.js
  -> вернуться на запомненную позицию
```

Пользователь видит короткую паузу с надписью «Меняем озвучку…». Ровно так же ведёт
себя оригинал, где каждая озвучка — тоже отдельный манифест. Код: `src/lib/player/controller.svelte.ts`.

### Вторая ключевая деталь: индекс TMDB → Jellyfin

**В Jellyfin нельзя найти тайтл по значению TMDB ID.** Параметр `AnyProviderIdEquals`
из Emby в Jellyfin сломан и возвращает всю библиотеку целиком, а `hasTmdbId=true`
фильтрует лишь по факту наличия любого идентификатора.

Поэтому приложение один раз обходит библиотеку, читает `ProviderIds.Tmdb` у каждого
элемента и строит обратную карту у себя (`src/lib/server/library-index.ts`). Индекс
лежит в `data/index.json`, переживает рестарт и пересобирается по расписанию.

Без этого индекса каталог не свяжется с медиатекой — это не оптимизация, а
обязательная часть.

## TMDB: три места, где легко наступить

1. **Язык не откатывается сам.** При `language=ru-RU` у тайтла без русского перевода
   приезжает `overview: ""` — пустая строка, не `null`. Поэтому в `details` запрашивается
   `append_to_response=translations`, и текст выбирается цепочкой `ru -> en` за один
   запрос. Точка принятия решения одна: `pickLocalized` в `src/lib/server/tmdb.ts`.

2. **`/tv/{id}/credits` отдаёт состав только последнего сезона.** Полный состав сериала —
   это `aggregate_credits`, и у него другая форма ответа: `roles[]` с `episode_count`
   вместо `character`. Общий рендерер с фильмами не подходит.

3. **`sort_by=vote_average.desc` без `vote_count.gte` возвращает мусор** — тайтлы с
   оценкой 10.0 по двум голосам. Порог подставляется всегда, см. `discover`.

Ещё: имена персон TMDB **не переводит** даже при `language=ru-RU` — это ограничение API,
кириллических имён в титрах не будет.

## Атрибуция — обязательна

Это не вежливость, а условие работы ключа:

- TMDB требует дословную формулировку «This product uses the TMDB API but is not
  endorsed or certified by TMDB» и свой логотип, менее заметный, чем ваш собственный.
- Данные о доступности на стримингах приходят от **JustWatch**, и его атрибуция —
  отдельное требование. За отсутствие отзывают доступ.
- Кэшировать данные TMDB дольше **шести месяцев** нельзя.
- Бесплатный ключ — только для некоммерческого использования.

Оба блока стоят в подвале (`src/lib/components/SiteFooter.svelte`). Если убираете
подвал — перенесите атрибуцию, а не удаляйте.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Без настроек поднимется **демо-режим**: встроенный каталог, четыре демонстрационные
озвучки и открытый тестовый поток. Полезно, чтобы посмотреть интерфейс до подключения
инфраструктуры.

### Боевая настройка

```bash
# .env
TMDB_API_KEY=...          # бесплатно: themoviedb.org/settings/api
JELLYFIN_URL=http://192.168.1.10:8096
JELLYFIN_API_KEY=...      # Dashboard -> API Keys, только для сборки индекса
SESSION_SECRET=...        # openssl rand -hex 32
DEMO_MODE=false
```

Пользователи входят своими учётными записями Jellyfin. Админский ключ нужен только
фоновому индексатору.

```bash
npm run build
node build/index.js
```

## Требования к Jellyfin

- **10.10+** — для нативного `MediaSegments` (пропуск заставок). На 10.9 работает, но кнопка «Пропустить заставку» не появится
- **Плагин TMDB** включён, метаданные подтянуты — иначе `ProviderIds.Tmdb` будет пустым и индекс останется пустым
- **Trickplay** сгенерирован (Dashboard → Playback → Trickplay) — для превью кадров на таймлайне
- **Intro Skipper** (опционально) — `github.com/intro-skipper/intro-skipper`, пишет тайминги в `MediaSegments`

## Структура

```
src/
  lib/
    server/
      jellyfin.ts        Клиент Jellyfin: авторизация, PlaybackInfo, отчёты
      tmdb.ts            Клиент TMDB: подборки, поиск, детали
      library-index.ts   Индекс TMDB -> Jellyfin
      catalog.ts         Сшивает TMDB с индексом, единственная точка стыка
      demo-data.ts       Демо-режим
      session.ts         Подписанные httpOnly-сессии
    player/
      controller.svelte.ts   Логика плеера, смена озвучки, отчёты
    components/
      Player.svelte      Плеер: контролы, озвучки, субтитры, Trickplay
      TitlePage.svelte   Страница тайтла
      MediaCard/Row      Каталог
  routes/
    api/playback/        resolve (в т.ч. смена озвучки) и progress
    movie|show/[slug]/   Страница тайтла и /watch
    catalog/             Фильмы и сериалы с фильтрами
```

## Замечание про токен

Медиа-URL (HLS-сегменты, субтитры, тайлы Trickplay) уходят в браузер с `api_key`
в query-строке — заголовок туда поставить нельзя. Это тот же подход, что в штатном
`jellyfin-web`. Токен пользовательский и ограничен его правами.

Если требуется, чтобы токен не покидал сервер, нужно проксировать поток через
приложение — ценой того, что весь видеотрафик пойдёт через Node. Для домашнего
сервера это обычно не оправдано.

## CDN-источники (Cobalt · Titan · Carbon)

Помимо Jellyfin, каталог играется через внешние CDN-скраперы — резолвер
`lightstream.ws/api/scrape` (env `SCRAPERS_ENABLED`, `SCRAPER_API_URL`).
Потоки Titan и Cobalt идут через same-origin прокси `/api/hls`, картинки
TMDB — через `/api/img` (обходит DNS-блокировки провайдеров).

Если API провайдера недоступен для датацентровых IP (бан), поднимите
свой прокси на Cloudflare Workers — готовый код в `cf-worker-proxy.js` —
и укажите его адрес в `SCRAPER_API_URL`.

## Деплой

Репозиторий привязан к Vercel: пуш в `main` собирает продакшн автоматически.
Переменные окружения задаются в Vercel (Project → Settings → Environment Variables):
`TMDB_API_KEY` (обязательно), остальные — по необходимости (см. `.env.example`).
