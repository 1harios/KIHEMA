# RUTUBE вместе

Вход: `/rutube`. Вставьте HTTPS-ссылку вида
`https://rutube.ru/video/564f31c881b83373bfe0cb26979d44cf/`, откройте ролик,
нажмите «Смотреть вместе» и создайте комнату. Приглашение находится в настройках
чата; друг открывает ссылку `/party/КОД` и вводит имя.

В существующей комнате ведущий может открыть настройки чата → «Видео RUTUBE»,
вставить следующую ссылку и нажать «Включить всем». Комната и сообщения
сохраняются при смене ролика, а все участники переходят на новый адрес.
Фильмы обычного каталога также можно переключать через «Сменить фильм».

## Воспроизведение и ограничения

- Используется официальный iframe/API https://rutube.ru/info/embed/.
  Видео загружает сам RUTUBE, а не наш TorrServer/прокси. Медиассылки,
  DRM-токены, обход ограничений и удаление рекламы не используются.
- Общие кнопки под видео управляют паузой и перемоткой всех зрителей.
  Крупные перемотки и пауза через собственные кнопки RUTUBE у ведущего
  также передаются комнате. У гостя используйте общие кнопки.
- Во время рекламы у любого зрителя или запроса разрешения autoplay общий
  контент ждёт. После готовности всех запускается обратный отсчёт.
  Браузер может потребовать один раз нажать Play непосредственно в RUTUBE.
- Качество выбирается отдельно у каждого зрителя, только из доступных
  уровней, полученных от официального плеера. Скорость общего просмотра — 1x.
- Полный экран открывайте нашей кнопкой: она включает весь кинозал вместе
  с чатом. На iPhone без element-fullscreen используется экранный режим.
- Реакции доступны и в компактном чате, отображаются над видео у всех.
  Заголовок и навигация автоматически скрываются при просмотре.
- Поддерживаются обычные публичные ролики и shorts, не прямые трансляции.
  Ролики с приватными ссылками/паролями и неразрешённым встраиванием не обещаны.
- Доступность на странице RUTUBE не гарантирует доступность в iframe.
  Ошибку провайдера невозможно исправить сервером KIHEMA; показываем сообщение,
  кнопку повтора и ссылку на оригинал. Ограничения сети/региона/рекламы
  определяет RUTUBE.

## Проверки

```sh
npm run check
node --test scripts/tests/*.test.mjs
python scripts/tests/party-server.test.py
node scripts/tests/browser-rutube.mjs http://127.0.0.1:5190
```

Последний тест использует два настоящих браузера и настоящий сервер комнат,
но **имитирует официальный API iframe**, чтобы воспроизводимо проверять
синхронизацию, рекламу, разрешение autoplay, реакции, мобильный чат и смену
ролика независимо от CDN RUTUBE. Это не проверка доступности самого видео.
Реальное видео проверяется отдельно в браузере без подмены iframe.

Обновление `deploy/vps/party-server.py` требует перезапуска `kihema-party`.
Существующие комнаты при этом очищаются; создайте новое приглашение.
